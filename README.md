# 1xBet 4-Method Odds Fetcher & Download Dashboard

ระบบดึงข้อมูลราคาต่อรอง (1X2, Asian Handicap, Over/Under) ครบทั้ง **4 วิธี** พร้อมหน้า **Web Dashboard** สำหรับเปรียบเทียบ ทดสอบดึงข้อมูลจริง และดาวน์โหลดไฟล์ได้หลายรูปแบบ (CSV, Normalized JSON, Raw JSON, Excel `.xls`, และ `.py` / `.zip` Bundle)

## ทั้ง 4 วิธีการดึงข้อมูลที่รองรับ

| วิธี | ค่าใช้จ่าย | ความเร็ว (Latency) | ความยากในการพัฒนาและดูแล | เหมาะกับงานประเภทไหน | ไฟล์สคริปต์ |
|---|---|---|---|---|---|
| **1. ยิง Internal Feed ตรง (LineFeed / LiveFeed)** | ฟรี 100% (ไม่จำกัด) | เร็วมาก (ระดับวินาที) | ยาก (แกะรหัส JSON เอง & จัดการ Proxy/บล็อก) | ข้อมูลสดความเร็วสูงและพร้อมดูแลระบบเลี่ยงบล็อกเอง | `fetchers/method1_internal_feed.py` |
| **2. Playwright / Selenium Network Interception** | ฟรี 100% (ไม่จำกัด) | ปานกลาง (ช้ากว่ายิงตรงเล็กน้อย) | ปานกลาง (เขียนง่ายกว่าแกะ Request แต่กิน RAM/CPU) | ดึงหลายตลาดพร้อมกันโดยไม่ปวดหัวเรื่อง Cookie/Token | `fetchers/method2_browser_intercept.py` |
| **3. Scrape จากเว็บกลาง (OddsPortal / Flashscore)** | ฟรี 100% (ไม่จำกัด) | ช้า (ดีเลย์ 10–30 วินาที) | ง่าย (ไม่ติดบล็อกในไทย มีโอเพ่นซอร์สศึกษาเยอะ) | เก็บสถิติย้อนหลัง (Backtest) หรือวิเคราะห์ก่อนแข่ง | `fetchers/method3_aggregator_scraper.py` |
| **4. OddsPapi (Free Tier)** | ฟรี (250 ครั้ง/เดือน) | เร็ว (โครงสร้างมาตรฐาน) | ง่ายที่สุด (เอกสารชัดเจน ข้อมูลสะอาดพร้อมใช้) | เริ่มต้นทดลองระบบ หรือดึงเฉพาะคู่ใหญ่ไม่กี่คู่/วัน | `fetchers/method4_oddspapi.py` |

## ฟีเจอร์หลักบน Dashboard

- **ตั้งค่าพารามิเตอร์ & บันทึกก่อนเรียกใช้:** เลือกโหมดก่อนแข่ง/สด, เลือก **กีฬาทั้งหมด (`All Sports`)** หรือแยก **20 ประเภทกีฬา/อีสปอร์ต**, กำหนดจำนวนคู่ต่อวิธี (1–1,000 คู่), และเลือก **ช่วงวันที่ (`date_from` ถึง `date_to`)** พร้อมปุ่มลัด `วันนี้`, `3 วัน`, `7 วัน`, `14 วัน`
- **แถบสถานะการทำงานแบบเรียลไทม์:** แสดงสถานะ `พร้อมใช้งาน` หรือ `กำลังดึงข้อมูล...` พร้อมตัวหมุน Progress Bar และนาฬิกาจับเวลาสด
- **ตารางเปรียบเทียบแบบ Dropdown:** กดเปิด/ปิดดูเปรียบเทียบทั้ง 4 วิธีได้อย่างสะอาดตา
- **ศูนย์เลือกดาวน์โหลด:** ส่งออกเป็น `CSV (UTF-8 BOM)`, `Excel (.xls)`, `Normalized JSON`, `Raw JSON`, หรือชุดสคริปต์ Python (`.py` / `.zip`)

## วิธีรัน Dashboard & QA

```cmd
python app.py
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8000` หรือรันชุดทดสอบ QA อัตโนมัติ:

```cmd
python qa_check.py
```
